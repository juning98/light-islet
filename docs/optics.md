# 光学模型与校验

光屿用三条传输路径比较罩片的效果：纹理改变光的传播方向，表面磨砂扩展出射方向，乳白亚克力在内部扩散入射光。三者可以独立组合，并用同一块 16 × 16 点阵观察差异。

## 参考场景

| 参数 | 模型取值 |
| --- | --- |
| 光源 | 16 × 16 个方形发光面，10 mm 节距，发光面宽 9.2 mm，间隙 0.8 mm，名义面板宽 160 mm |
| 亚克力基底 | 折射率 1.49；清晰光路的吸收系数为 0.001/mm；基底厚度可调 0.5–20 mm |
| 空气间隙 | 0–200 mm，从发光面到罩片底面，不含基底和纹理起伏 |
| 默认设置 | 透明亚克力、3 mm 基底、8 mm 空气间隙、横向波纹 1.2×、单面磨砂 24% |

## 纹理折射

[`shaders.js`](../src/optics/shaders.js) 在正交视角下逐像素计算纹理的高度与法线，沿观察方向反向求光路。光线按 Snell 定律穿过罩片的两个界面，再投到发光平面；传输系数计入非偏振 Fresnel 透射率和 Beer–Lambert 吸收，全反射路径在这一步剔除。直视发光面的辐亮度与空气间隙无关；体散射收到的照度由有限光源的几何关系决定。

基底厚度与纹理起伏分开。基底薄于 3 mm 时缩小纹理起伏，避免表面穿过底面。

## 表面磨砂

[`transport.js`](../src/optics/transport.js) 用归一化的高斯角分布近似磨砂，分布中心由纹理折射决定。每颗灯都按 9.2 mm 方形面积用误差函数积分，灯珠之间的暗缝自然保留在光源模型里。连续积分会把光分摊到一片区域，避免少量固定采样方向形成离散重影。

设 `r` 为 0–1 的粗糙度，`d` 为空气间隙，`t` 为基底厚度，角度标准差为 `s = (1.49 − 1) × 1.2r`。观察者一侧的磨砂使横向方差增加 `s²(d + t/1.49)²`；双面磨砂再加入朝向 LED 那一侧的 `s²d²`。参考表面散射比例为 `1 − exp(−18r × 磨砂面数)`。界面上的百分比控制的是模型粗糙度，并非实测雾度。

## 乳白体散射

乳白材料把光分成内部直透与扩散两部分，内部直透权重为 `exp(−2.4t)`，参考体透射率为 `exp(−0.015t) / (1 + 0.22t)`，再计入界面透射与基底吸收。关闭表面磨砂后，这些体散射项仍然参与计算。

模型用有限 Lambert 发光面的照度计算罩片能收到多少光。对于横向距离 `ρ` 和有效传播距离 `z = d + t/2`，归一化核为 `z² / [π(z² + ρ²)²]`。它可以写成连续高斯混合，通过换元 `u = exp(−q)` 做七点 Gauss–Legendre 积分，再对每个方形发光面积分。内部横向扩散与表面磨砂的方差随后叠加。间隙增大时，有限面板照到罩片的能量自然减弱。

## 实时渲染

[`renderer.js`](../src/optics/renderer.js) 把面积积分分成 GPU 的横向和纵向两步。光源暂停且传输参数不变时复用积分结果，拖动仍在每帧更新折射。光场在计算时保持线性辐亮度；缓冲区优先使用半浮点格式，也支持平方根编码的 RGBA8。画面最后进行色调映射和 sRGB 转换，并用固定抖动减少暗部色带。

## 校验与标定范围

`npm run test:optics` 校验单颗发光面的积分总量、独立数值积分的一致性、距离与双面磨砂的响应、乳白材料的厚度响应，以及有限面板的照度。30 个距离和位置组合与解析矩形发光面解比较后，归一化照度的最大绝对误差约为 **0.515 个百分点**。这个数字衡量积分近似的误差。

光源尺寸、表面角分布和乳白材料系数均是参考预设。模型适合在相同条件下比较参数带来的变化；要匹配实际 LED 模组或亚克力牌号，需要实测尺寸、透射率和散射分布。观察角度固定，模型未完整求解粗糙介质多次散射、内部反射、侧壁、偏振、衍射和光谱色散。
